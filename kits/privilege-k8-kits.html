Single node

1 Gateway Privilege K8

Simplest working deployment: one gateway node, no Redis, no load balancer. Client registrations live in gateway memory.

  • docs/ — deployment guide PDF (18 pp) with a Quick Start section + generator
  • helm/ — agent-privilege-0.1.0.tgz, quickstart-values.yaml, chart source
  • tf/ — Terraform for namespaces, secrets and the gateway release

High availability

Multi-Gateway Privilege K8

Full HA platform: shared Redis (registrations survive restarts/failover), integrated load balancer, multiple gateway nodes in one mesh cluster.

  • helm releases + Redis — one release per node, MCPGW_REDIS_URL wired to every namespace
  • load balancer — client pinning, callback routing, health checks (integrated, or bring Kong / F5 / HAProxy)
  • Guide — covers HAProxy, Kong and F5 BIG-IP example configs (§7.2–7.4)
